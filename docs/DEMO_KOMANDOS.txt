DONE N DUSTED - komandos gynimui (LD1)
=======================================

Seed duomenys, kuriuos naudoju:
  Guild 1 = Thursday Night Crew
  Guild 2 = Iron Vow
     Quest 4 = Run 50 kilometers (GRIND, HARD -> 50 XP), turi logus 4,5 (APPROVED), 6 (REJECTED), 7 (PENDING)
     Quest 6 = Deadlift bodyweight x2 (LEGENDARY -> 80 XP)
     Quest 7 = Winter swim challenge (NEAKTYVI)
  Guild 3 = The Quiet Library


-----------------------------------------------------------------
0. PALEIDIMAS
-----------------------------------------------------------------

Terminale projekto aplanke:

./mvnw spring-boot:run

Laukiu eilutes "Started DoneNDustedApplication". Pirma karta ilgiau, nes siuncia PostgreSQL.
Sustabdau su Ctrl+C tame paciame terminale (ne uzdarant langa!), kitaip postgres.exe
lieka veikti ir kitas paleidimas nepavyks, nes 55432 portas uzimtas.
Jei taip nutiko: PowerShell'yje  Get-Process postgres | Stop-Process -Force

Narsykleje atsidarau:
  http://localhost:8080/swagger-ui.html     <- Swagger UI, visi 15 metodu su aprasymais
  http://localhost:8080/v3/api-docs         <- OpenAPI JSON (tas pats kas docs/openapi.json)
  http://localhost:8080/api/guilds          <- tiesiog API

Duomenu baze (jei paklaus ar tikrai PostgreSQL) - DBeaver:
  host localhost, port 55432, db postgres, user postgres, slaptazodzio nera
  Ten matosi lenteles guild, quest, log_entry ir flyway_schema_history.

Antrame terminale (Git Bash) paleidziu visa Postman kolekcija - 28 uzklausos, 57 patikros, ~5 s:

npx newman run postman/DoneNDusted.postman_collection.json

Jei leidziu per PowerShell ir meta "running scripts is disabled on this system" - tai
Windows neleidzia paleisti npx.ps1 skripto. Tada naudoju .cmd versija:

npx.cmd newman run postman/DoneNDusted.postman_collection.json

(arba Postman programoje: Import -> kolekcija -> Run)


-----------------------------------------------------------------
1. GUILD - 5 metodai
-----------------------------------------------------------------

# 1.1 Sarasas (200). Atsakyme content + page + links (self/first/next/last)
curl -s http://localhost:8080/api/guilds

# 1.2 Puslapiavimas ir rikiavimas - atsiranda next nuoroda, o filtrai nuorodose islieka
curl -s "http://localhost:8080/api/guilds?page=0&size=2&sort=name,desc"

# 1.3 Filtras pagal pavadinima (nesvarbu didziosios/mazosios raides)
curl -s "http://localhost:8080/api/guilds?name=iron"

# 1.4 Viena grupe (200)
curl -s http://localhost:8080/api/guilds/2

# 1.5 Sukurti grupe (201 + Location antraste). -i parodo antrastes
R=$(curl -si -X POST http://localhost:8080/api/guilds -H "Content-Type: application/json" -d '{"name":"Gynimo grupe","description":"Sukurta per gynima"}'); echo "$R"

# (POST ir id paemimas is Location antrastes i kintamaji GID, kad toliau nereiktu ranka rasyti)
GID=$(echo "$R" | tr -d '\r' | grep -i '^location' | grep -o '[0-9]*$'); echo "Nauja grupe: $GID"

# 1.6 Atnaujinti (200)
curl -s -X PUT http://localhost:8080/api/guilds/$GID -H "Content-Type: application/json" -d '{"name":"Gynimo grupe v2","description":"Pakeistas aprasymas"}'

# 1.7 Istrinti (204, kuno nera). Paskui GET -> 404
curl -i -X DELETE http://localhost:8080/api/guilds/$GID
curl -s http://localhost:8080/api/guilds/$GID

2. QUEST - 5 metodai (visada per grupe!)
-----------------------------------------------------------------

# 2.1 Grupes 2 uzduotys (200)
curl -s http://localhost:8080/api/guilds/2/quests

# 2.2 Filtrai: stat, type, difficulty, active
curl -s "http://localhost:8080/api/guilds/2/quests?stat=CON&active=true"
curl -s "http://localhost:8080/api/guilds/2/quests?type=GRIND"

# 2.3 Viena uzduotis (200)
curl -s http://localhost:8080/api/guilds/2/quests/4

# 2.4 Sukurti GRIND uzduoti (201 + Location)
R=$(curl -si -X POST http://localhost:8080/api/guilds/2/quests -H "Content-Type: application/json" -d '{"title":"Gynimo push-ups","stat":"STR","type":"GRIND","difficulty":"MEDIUM","targetCount":100}'); echo "$R"

QID=$(echo "$R" | tr -d '\r' | grep -i '^location' | grep -o '[0-9]*$'); echo "Nauja uzduotis: $QID"

# 2.5 Atnaujinti (200) - pakeiciu i HABIT, tada targetCount nebeduodu
curl -s -X PUT http://localhost:8080/api/guilds/2/quests/$QID -H "Content-Type: application/json" -d '{"title":"Gynimo push-ups","stat":"STR","type":"HABIT","difficulty":"EASY","active":true}'

# 2.6 Istrinti (204)
curl -i -X DELETE http://localhost:8080/api/guilds/2/quests/$QID

3. LOG ENTRY - 5 metodai (per grupe ir uzduoti)
-----------------------------------------------------------------

# 3.1 Uzduoties 4 irasai (200), naujausi pirmi
curl -s http://localhost:8080/api/guilds/2/quests/4/logs

# 3.2 Filtras pagal busena
curl -s "http://localhost:8080/api/guilds/2/quests/4/logs?status=APPROVED"

# 3.3 Vienas irasas (200)
curl -s http://localhost:8080/api/guilds/2/quests/4/logs/4

# 3.4 Sukurti irasa prie LEGENDARY uzduoties 6 (201). Atsakyme status=PENDING, xpAwarded=0
R=$(curl -si -X POST http://localhost:8080/api/guilds/2/quests/6/logs -H "Content-Type: application/json" -d '{"note":"Pakeliau 140 kg!","evidenceUrl":"https://example.org/deadlift.mp4","occurredAt":"2026-09-20T10:00:00Z"}'); echo "$R"

LID=$(echo "$R" | tr -d '\r' | grep -i '^location' | grep -o '[0-9]*$'); echo "Naujas irasas: $LID"

# 3.5 DM patvirtina BE xpAwarded -> serveris pats paskaiciuoja 80 XP (LEGENDARY 8 x 10)
curl -s -X PUT http://localhost:8080/api/guilds/2/quests/6/logs/$LID -H "Content-Type: application/json" -d '{"note":"Pakeliau 140 kg!","evidenceUrl":"https://example.org/deadlift.mp4","occurredAt":"2026-09-20T10:00:00Z","status":"APPROVED","reviewerNote":"Video matosi, uzskaitau"}'

# 3.6 Istrinti (204)
curl -i -X DELETE http://localhost:8080/api/guilds/2/quests/6/logs/$LID

4. KLAIDOS - visos grizta vienodu ApiError formatu
-----------------------------------------------------------------

# 404 - neegzistuojantis resursas
curl -s http://localhost:8080/api/guilds/999

# 404 - NETEISINGA GRANDINE: quest 4 egzistuoja, bet jis grupeje 2, ne 1
curl -s http://localhost:8080/api/guilds/1/quests/4

# 404 - log 4 egzistuoja, bet ne prie uzduoties 5
curl -s http://localhost:8080/api/guilds/2/quests/5/logs/4

# 400 - validacija: tuscias vardas, details nurodo kuri lauka
curl -s -X POST http://localhost:8080/api/guilds -H "Content-Type: application/json" -d '{"name":""}'

# 400 - sugadintas JSON
curl -s -X POST http://localhost:8080/api/guilds -H "Content-Type: application/json" -d '{"name": '

# 400 - nezinoma enum reiksme
curl -s -X POST http://localhost:8080/api/guilds/2/quests -H "Content-Type: application/json" -d '{"title":"Blogas","stat":"LUCK","type":"HABIT","difficulty":"EASY"}'

# 400 - id ne skaicius
curl -s http://localhost:8080/api/guilds/abc

# 400 - rikiavimas pagal neegzistuojanti lauka
curl -s "http://localhost:8080/api/guilds?sort=bogus"

# 400 - bandau kuriant irasa pats prisiskirti XP (tokio lauko create DTO nera)
curl -s -X POST http://localhost:8080/api/guilds/2/quests/4/logs -H "Content-Type: application/json" -d '{"note":"Noriu tasku","occurredAt":"2026-09-20T10:00:00Z","xpAwarded":9999}'

# 409 - toks grupes pavadinimas jau yra
curl -s -X POST http://localhost:8080/api/guilds -H "Content-Type: application/json" -d '{"name":"Iron Vow"}'

# 415 - kunas ne JSON
curl -s -X POST http://localhost:8080/api/guilds -H "Content-Type: text/plain" -d 'labas'

# 406 - prasau XML, o API grazina tik JSON
curl -s -i http://localhost:8080/api/guilds -H "Accept: application/xml" | head -1

# 405 - metodas netinka siam keliui
curl -s -X PATCH http://localhost:8080/api/guilds/2

# 422 - GRIND be targetCount (JSON geras, bet pazeista taisykle)
curl -s -X POST http://localhost:8080/api/guilds/2/quests -H "Content-Type: application/json" -d '{"title":"Grind be tikslo","stat":"STR","type":"GRIND","difficulty":"EASY"}'

# 422 - targetCount ne GRIND tipui
curl -s -X POST http://localhost:8080/api/guilds/2/quests -H "Content-Type: application/json" -d '{"title":"Habit su tikslu","stat":"STR","type":"HABIT","difficulty":"EASY","targetCount":5}'

# 422 - irasas prie neaktyvios uzduoties 7
curl -s -X POST http://localhost:8080/api/guilds/2/quests/7/logs -H "Content-Type: application/json" -d '{"note":"Plaukiau","occurredAt":"2026-09-20T10:00:00Z"}'

# 422 - occurredAt ateityje
curl -s -X POST http://localhost:8080/api/guilds/2/quests/4/logs -H "Content-Type: application/json" -d '{"note":"Rytoj begsiu","occurredAt":"2099-01-01T10:00:00Z"}'

# 422 - REJECTED irasui bandau duoti XP
curl -s -X PUT http://localhost:8080/api/guilds/2/quests/4/logs/7 -H "Content-Type: application/json" -d '{"occurredAt":"2026-09-20T10:00:00Z","status":"REJECTED","xpAwarded":50}'

5. KASKADINIS TRYNIMAS (jei paklaus kas nutinka vaikams)

# Sukuriu grupe -> uzduoti -> irasa, istrinu grupe, ir uzduotis dingsta kartu (ON DELETE CASCADE)
R=$(curl -si -X POST http://localhost:8080/api/guilds -H "Content-Type: application/json" -d '{"name":"Kaskados grupe"}'); echo "$R"
CG=$(echo "$R" | tr -d '\r' | grep -i '^location' | grep -o '[0-9]*$')

curl -i -X DELETE http://localhost:8080/api/guilds/$CG
curl -s http://localhost:8080/api/guilds/$CG/quests
